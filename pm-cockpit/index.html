How it works

This is one HTML file. Open it by double-clicking, or drop it on any static host (SharePoint, an internal file share, GitHub Pages). When you load your Gold Copy, the browser reads it on your machine — no server, no upload, no storage.

Excel (.xlsx): the tool reads your deliverables sheet plus any tabs named Dependencies, Assumptions, Issues, Decisions, or Risks. CSV: export a single tab; load it the same way (RAID diffing still works if you load the RAID tab as the file).

Column names don't have to be exact — the tool fuzzy-matches common header variations. Here's what it looks for:

Deliverables tab

ID — id, ref, line #
Workstream — workstream, initiative, program, track, epic
Deliverable — deliverable, task, name, title, activity
Owner — owner, lead, DRI, assignee
Start — start, start date, baseline start
End — end, finish, due, target date
Status — status, health, RAG
% Complete — %, progress, complete
Milestone — milestone / type = milestone

RAID tabs

Sheets named Dependencies, Assumptions, Issues, Decisions, Risks.

Description — description, title, summary, item
Owner — owner, lead, DRI
Status — status (open/in progress/closed)
Severity — severity, priority, impact, RAG
Date — date raised, due, target
Notes — mitigation, response, action, notes

Status colors

Complete done / closed

On Track on track / green

At Risk at risk / amber

Off Track delayed / red / blocked

Not Started planned / new

Change Digest — compare two versions of any spreadsheet

Works on any tracking file, not just the Gold Copy. Load an older and newer version; the tool matches rows by an identity column you pick (ID, Ticket #, Name…) and shows exactly which rows were added, removed, and which individual cells changed — old value struck through, new value in green. No macros, no change tracking, and it never modifies or uploads your file.

If it recognizes a Gold Copy (date + status columns, and/or RAID tabs), it adds an Executive summary on top: completions, date slips (with day counts), status changes, and new/closed RAID items — the readout-ready narrative — while still giving you the full cell-level diff underneath.

Tips: if your sheet has no ID column, switch “Match rows by” to Row position. You can pick multiple identity columns to form a composite key. Only columns present in both files are compared for cell edits; added/removed columns are called out separately. Use Download change report (.csv) to save the list of changes.
