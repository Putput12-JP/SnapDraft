Design notes

Shell. Four dock anchors (Home, Research, League, Portfolio) plus the Vault Command puck; every secondary tool is exactly two taps away, so nothing needs a desktop-only nav anymore. antd-mobile mapping. NavBar for every screen top, CapsuleTabs for in-page mode switches, underline Tabs for peer views, List for all data rows, FloatingPanel for the player sheet and Command grid, Steps + Result for the Calc flow, Badge on the League tab for pending trades. Motion. Sheets use the iOS curve (0.32, 0.72, 0, 1) at 350 to 450ms; tab swaps are instant or a 150ms fade; list sorts never animate. Type. Archivo for UI, JetBrains Mono strictly for numbers, grades and kickers, exactly as on desktop.
